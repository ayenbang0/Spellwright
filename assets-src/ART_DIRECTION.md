# Magicraft Clone — Pixel Art Direction (Web Prototype)

Goal: ultra-readable bullet-hell. Player must tell in 0.1s: **who shot what, what element, what behavior**.

## Rules
- **Base size:** 16px enemies/projectiles/tiles/icons, 24px player, 16x20 NPCs, elites = base sprite + crown (x1.35 in-engine), 48px bosses. Display x4 with `image-rendering: pixelated`.
- **Minimalist style:** strong silhouette, 1px dark outline (`#0a0a10`), 3-tone ramps (shadow/base/highlight, light from top-left), few colours per sprite. Hostile units carry magenta/red eyes or accents.
- **Silhouette first:** circle=friendly/heal, square=physical/rock, diamond/triangle=pierce, jagged=lightning, blob=slime/poison, star=nova/special, cross=absorb. Never rely on color alone.
- **Element colors (always same):**
  - Arcane/cyan `#22D3EE` white core, Fire `#F97316`+`#EF4444`, Ice `#A5F3FC` border, Lightning `#FACC15` jagged, Poison `#4ADE80` bubbles, Void `#A855F7` on `#1E1B4B`, Blood `#DC2626`, Bone `#E7E5E4`, Gold `#FBBF24`
  - Enemy bullets: **magenta/red with white outline** vs player **cyan/white with dark outline** — never mix.
- **Animation beats (attack readability):**
  1. `telegraph` 0.3s red circle/line, 2. `windup` 0.1s white flash + scale 1.2x, 3. `fire` spawn + trail, 4. `impact` 3-frame explosion. Every boss/enemy uses same timing.
- **Modifier stacking (visual):** base sprite + tint border + behavior icon + trail change. See `assets/manifest.json -> visualStacking`.
  - Homing=cyan chevrons `>>>`, Rebound=green double-arrow, Pierce=white line through, Multi/Volley=ghost copies + count pips, Fire=flame fringe, Frost=snow corners, Venom=bubbles top, Thunder=sparks, Orbit=dashed ring, Duet=chain link, Echo=faded copy.
- Every sprite that moves animates (`_f0..fN`, 8-12 fps); hit flash = `_hit.png` white silhouette; bosses have `_telegraph.png` with a red warning glow.
- Files are generated by `tools/gen_art.py` (Pillow, no external assets, deterministic). Preview in `assets/preview.html`.
